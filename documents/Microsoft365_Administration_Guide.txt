1. INTRODUCTION
---------------
This guide covers the administration of Microsoft 365 services at TechCore Solutions including Exchange Online, SharePoint, Teams, OneDrive, and Intune. All IT administrators must follow these procedures when managing Microsoft 365 services.

Admin Centre URLs:
- Microsoft 365 Admin Centre: admin.microsoft.com
- Exchange Admin Centre: admin.exchange.microsoft.com
- SharePoint Admin Centre: admin.sharepoint.com
- Teams Admin Centre: admin.teams.microsoft.com
- Intune Admin Centre: intune.microsoft.com
- Azure Active Directory: aad.portal.azure.com
- Microsoft Defender: security.microsoft.com

2. USER MANAGEMENT
-------------------
Creating a New User in Microsoft 365:
1. Log into admin.microsoft.com
2. Navigate to Users then Active Users
3. Click Add a user
4. Enter First name, Last name, Display name, and Username
5. Username format: firstname.lastname@techcore.com
6. Select auto-generate password or create a custom password
7. Check Require this user to change their password when they first sign in
8. Click Next
9. Assign the appropriate licence based on role
10. Assign roles if the user needs admin access
11. Click Next then Finish adding

Assigning Admin Roles:
Global Administrator: Full access to all Microsoft 365 services. Only 2 accounts should have this role.
Exchange Administrator: Manages Exchange Online mailboxes and settings.
SharePoint Administrator: Manages SharePoint sites and settings.
User Administrator: Creates and manages user accounts and resets passwords.
Helpdesk Administrator: Resets passwords for non-admin users only.
Teams Administrator: Manages Teams settings and policies.
Intune Administrator: Manages device enrolment and policies.

To Assign a Role:
1. Go to admin.microsoft.com
2. Navigate to Users then Active Users
3. Click on the user
4. Click Manage roles
5. Select the appropriate role
6. Click Save changes

3. EXCHANGE ONLINE ADMINISTRATION
-----------------------------------
Mailbox Management:
Creating a Shared Mailbox:
1. Go to admin.exchange.microsoft.com
2. Navigate to Recipients then Mailboxes
3. Click Add a shared mailbox
4. Enter Display name and Email address
5. Click Create
6. Add members who need access to the shared mailbox
7. Members can access the shared mailbox from Outlook without a separate password

Creating a Distribution Group:
1. Go to admin.exchange.microsoft.com
2. Navigate to Recipients then Groups
3. Click Add a group
4. Select Distribution list as group type
5. Enter group name and email address
6. Add members
7. Click Create

Email Forwarding Setup:
1. Go to admin.exchange.microsoft.com
2. Navigate to Recipients then Mailboxes
3. Click on the user mailbox
4. Click Manage email forwarding
5. Toggle on Forward all emails sent to this mailbox
6. Enter the forwarding email address
7. Choose whether to keep a copy in the original mailbox
8. Click Save

Mailbox Size Limits:
Standard Staff: 50GB
Managers: 100GB
Executives: Unlimited
Shared Mailboxes: 50GB (no licence required up to 50GB)

Mail Flow Rules:
Mail flow rules control how emails are processed. Common rules at TechCore:
- Auto-append disclaimer to all outgoing emails
- Block emails with executable attachments
- Encrypt emails containing sensitive keywords
- Route emails from specific domains to specific mailboxes

To Create a Mail Flow Rule:
1. Go to admin.exchange.microsoft.com
2. Navigate to Mail flow then Rules
3. Click Add a rule
4. Select the appropriate template or create from scratch
5. Define conditions and actions
6. Set rule priority
7. Click Save

4. SHAREPOINT ADMINISTRATION
------------------------------
SharePoint Site Types:
Team Site: For department collaboration with Members, Visitors, and Owners permission groups.
Communication Site: For broadcasting information to a wider audience. Typically used for company intranet.
Hub Site: Connects related sites together for consistent navigation and branding.

Creating a New SharePoint Site:
1. Go to admin.sharepoint.com
2. Click Create
3. Choose Team site or Communication site
4. Enter site name, description, and privacy setting
5. Select language and time zone
6. Click Finish
7. Add site owners and members

SharePoint Permission Groups:
Owners: Full control of the site. Can manage permissions and settings. Reserved for site administrators.
Members: Can add, edit, and delete content. Standard access for team members.
Visitors: Read-only access. Use for stakeholders who only need to view content.

Managing External Sharing:
External sharing allows sharing with users outside TechCore Solutions.
By default external sharing is disabled for all sites.
To enable external sharing:
1. Go to admin.sharepoint.com
2. Click on the site
3. Click Sharing
4. Select the appropriate sharing level
5. New and existing guests: allows sharing with anyone who accepts the invitation
6. Existing guests only: only users already in Azure AD directory
7. Only people in your organisation: no external sharing

OneDrive Administration:
Each user gets 1TB of OneDrive storage.
Storage quota can be increased by contacting Microsoft Support.
Files deleted from OneDrive go to the recycle bin for 93 days before permanent deletion.
Admins can access user OneDrive through SharePoint Admin Centre for compliance purposes.

5. MICROSOFT TEAMS ADMINISTRATION
-----------------------------------
Teams Policies:
Teams policies control what users can do in Teams. Policies are applied per user or per group.

Messaging Policy: Controls chat features like GIFs, stickers, and read receipts.
Meeting Policy: Controls meeting features like recording, transcription, and lobby settings.
App Permission Policy: Controls which apps users can install in Teams.
Calling Policy: Controls calling features like voicemail and call forwarding.

Creating a New Team:
1. Go to admin.teams.microsoft.com
2. Navigate to Teams then Manage teams
3. Click Add
4. Enter team name and description
5. Select privacy: Private (invite only) or Public (anyone can join)
6. Add team owners and members
7. Click Apply

Meeting Settings:
Recording Policy:
- Meeting recordings are stored in OneDrive or SharePoint
- Recordings are automatically deleted after 60 days unless saved
- Recording requires organiser permission

Lobby Settings:
- External guests are placed in the lobby by default
- Organisers must admit guests from the lobby
- Internal users bypass the lobby by default

Teams Phone (VoIP):
TechCore uses Teams Phone for internal calling.
Extension numbers are assigned in the format 1xxx.
IT Department extensions: 1001 to 1099
Finance extensions: 1100 to 1199
HR extensions: 1200 to 1299
Sales extensions: 1300 to 1399

6. MICROSOFT INTUNE ADMINISTRATION
------------------------------------
Intune manages all company devices including Windows laptops, iOS phones, and Android devices.

Device Enrolment:
Windows Autopilot Enrolment:
1. New devices are pre-registered in Autopilot by the vendor
2. User powers on the device and connects to internet
3. Device automatically detects Autopilot configuration
4. User signs in with Microsoft 365 credentials
5. Device automatically joins Azure AD and enrols in Intune
6. Company policies and applications are pushed automatically
7. Process takes approximately 30 to 60 minutes

Manual Windows Enrolment:
1. Go to Settings then Accounts then Access work or school
2. Click Connect
3. Enter company Microsoft 365 email address
4. Follow the prompts to complete enrolment
5. Restart the device when prompted

iOS Enrolment:
1. Install Intune Company Portal from App Store
2. Open Company Portal and sign in with Microsoft 365 credentials
3. Follow the enrolment prompts
4. Install the management profile when prompted
5. Grant required permissions

Compliance Policies:
All enrolled devices must meet these compliance requirements:
- Operating system must be up to date (within 30 days of latest update)
- Antivirus must be enabled and up to date
- BitLocker encryption must be enabled (Windows)
- Screen lock with PIN or biometric must be configured
- Device must not be jailbroken or rooted
- Minimum OS version: Windows 11 22H2, iOS 16, Android 12

Non-Compliant Devices:
If a device becomes non-compliant:
1. User receives notification to bring device into compliance
2. Device has 7 days to become compliant
3. After 7 days non-compliant devices lose access to company resources
4. IT receives alert for devices that remain non-compliant

Remote Actions:
IT administrators can perform these actions remotely on enrolled devices:
- Wipe: Removes all data and resets device to factory settings. Use for lost devices.
- Retire: Removes company data and unenrols device. Use when employee leaves.
- Sync: Forces device to check in with Intune and apply latest policies.
- Restart: Remotely restarts the device.
- Lock: Remotely locks the device with a PIN.
- Rotate BitLocker key: Generates new BitLocker recovery key.

7. AZURE ACTIVE DIRECTORY
--------------------------
Conditional Access Policies:
Conditional Access controls access to company resources based on conditions.

Current Policies at TechCore:
Require MFA for all users: All users must complete MFA for every sign-in.
Block legacy authentication: Prevents use of older protocols that bypass MFA.
Require compliant device: Company resources only accessible from Intune enrolled devices.
Block access from high-risk locations: Sign-ins from unusual locations require additional verification.
Block risky sign-ins: Automatically blocks sign-ins Microsoft detects as high risk.

Identity Protection:
Azure AD Identity Protection monitors for risky behaviour:
- Sign-ins from unfamiliar locations
- Sign-ins from anonymous IP addresses
- Impossible travel (signing in from two different countries simultaneously)
- Password spray attacks
- Leaked credentials found on dark web

When a risky sign-in is detected:
1. User is prompted to reset their password
2. IT Security receives an alert
3. If risk level is high, account is automatically blocked
4. IT Security investigates and clears the risk or confirms compromise

Sign-in Logs:
All sign-ins are logged in Azure AD for 30 days.
To review sign-in logs:
1. Go to aad.portal.azure.com
2. Navigate to Users then find the user
3. Click Sign-in logs
4. Filter by date, application, or status
5. Export logs for long-term retention if required

8. MICROSOFT DEFENDER FOR MICROSOFT 365
-----------------------------------------
Microsoft Defender protects against email, identity, and endpoint threats.

Anti-Phishing Policies:
- Impersonation protection monitors for emails pretending to be executives
- Mailbox intelligence learns user email patterns to detect anomalies
- Safe Links scans all URLs in emails and blocks malicious links in real time
- Safe Attachments opens attachments in a sandbox before delivering to users

Threat Explorer:
Used to investigate suspected security threats:
1. Go to security.microsoft.com
2. Navigate to Email and collaboration then Explorer
3. Search by sender, recipient, subject, or URL
4. View detailed information about suspicious emails
5. Take action to delete or quarantine emails

Quarantine Management:
Emails detected as spam or malware are quarantined.
Users receive a quarantine digest email showing quarantined messages.
IT administrators can release or delete quarantined emails:
1. Go to security.microsoft.com
2. Navigate to Email and collaboration then Quarantine
3. Review quarantined items
4. Release legitimate emails or delete confirmed spam

9. LICENCE MANAGEMENT
-----------------------
Licence Types at TechCore Solutions:
Microsoft 365 Business Basic: Email, Teams, SharePoint, OneDrive. No desktop Office apps.
Microsoft 365 Business Standard: All Basic features plus desktop Office apps (Word, Excel, PowerPoint).
Microsoft 365 E3: All Standard features plus advanced security, compliance, and analytics.

Licence Assignment:
General Staff: Business Basic
Managers and Directors: Business Standard
IT Staff and Executives: E3

Checking Available Licences:
1. Go to admin.microsoft.com
2. Navigate to Billing then Licences
3. View available and assigned licences for each product
4. Purchase additional licences if needed

Removing Licences (Offboarding):
1. Go to admin.microsoft.com
2. Navigate to Users then Active Users
3. Find the departing user
4. Click Licences and Apps
5. Uncheck all assigned licences
6. Click Save changes
7. The mailbox becomes inactive and data is retained for 30 days
