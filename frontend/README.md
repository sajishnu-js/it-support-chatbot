# TechCore IT — Frontend

Next.js (App Router) + TypeScript + Tailwind CSS + shadcn/ui frontend for the TechCore IT Knowledge Assistant.

See the [repository root README](../README.md) for full setup instructions (this app requires the FastAPI backend running at `NEXT_PUBLIC_API_URL`, default `http://localhost:8000`).

```bash
npm install
cp .env.local.example .env.local
npm run dev
```
